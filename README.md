A 100-word monologue for a fantasy villain who is secretly just very tired.

`main.ts` (Node 22, stdlib only) writes one monologue to `/output/entry.txt`.
The Dark Lord meant to unmake the sun this week — eclipse chalked, choir
rehearsed, blade sharp — but the east granaries burned, a clerk filed the
ash as "miscellaneous", and the end of the world slipped to Thursday.
Or Friday. The tiredness lives in the pauses, the deflections and the
rescheduled apocalypse, never in a plain statement that he is weary.

Run it:

```sh
node main.ts
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), 103 words,
559 characters, inside the gate's 1–600 characters.
